# HonestDrifter

With the Artifact of Command enabled, the temporary items the Drifter salvages come out as Command Cubes: you have to pick one of several random options instead of getting the item the Drifter dropped. HonestDrifter makes Salvage drop the item as a regular pickup on the ground.

## What it changes

- Temporary items dropped by the Drifter's Salvage are never wrapped in a Command Cube, even when the Artifact of Command is enabled.
- Salvaged items fall to the ground as normal pickups, the same as without the artifact.
- Other Command Cubes (chests, shrines, and so on) work as before.

## Dependencies

Your mod manager installs these automatically:

- BepInExPack
- HookGenPatcher
